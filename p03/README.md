# Program Pengolahan Data Suhu

## Deskripsi
Program ini digunakan untuk mengolah data suhu dengan menghitung rata-rata,
mencari nilai suhu tertinggi, dan menentukan status suhu berdasarkan nilai yang diperoleh.

## Cara Menjalankan Program
Jalankan perintah berikut pada terminal:

python main.py

## Cara Menjalankan Test
Jalankan perintah berikut pada terminal:

python -m pytest
